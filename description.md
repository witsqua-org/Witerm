# Witerm

An SSH client and Mac terminal continuity app for macOS and iOS.

- Native SwiftUI apps with SwiftTerm rendering and a dedicated SSH engine.
- A user-level Mac background service keeps sessions alive in a private tmux server.
- A Go and PostgreSQL server pairs devices and relays end-to-end encrypted terminal traffic.
- iOS connects to SSH servers directly, without a Mac or the server.
- Follows the system language (English, Simplified Chinese) and light/dark appearance.

See [README.md](README.md) to get started and [docs/architecture.md](docs/architecture.md) for the design.
