# Witerm

An SSH client and Mac terminal continuity app for macOS, iPhone, and iPad.

- Direct SSH from Mac and iOS, with no server involved.
- Mac terminals that keep running after the app quits, hosted by a user-level service in a private tmux server.
- The `witerm` command starts, shares, and attaches to the same sessions from any terminal.
- Paired iPhones and iPads continue shared Mac sessions through an end-to-end encrypted relay (Go and PostgreSQL).
- Native SwiftUI with SwiftTerm, in English and Simplified Chinese, following the system's light/dark appearance.
